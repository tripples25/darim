# Windows backup archive crypto check

Date: 2026-11-13

Implemented and exercised the synthetic archive layer in
`ops/windows-backup/ArchiveCrypto.psm1`. It encrypts payloads up to 32 MiB with
AES-256-CBC, authenticates the versioned header and ciphertext with HMAC-SHA256,
and wraps the per-archive encryption/authentication keys with CurrentUser DPAPI.
Recovery-key export is optional and uses PBKDF2-HMAC-SHA256 plus authenticated
AES-256 encryption. Files are published atomically from a `.partial` file.

The tests use only randomly generated bytes and a synthetic marker. They cover
round-trip of a payload larger than the 1 MiB read buffer, absence of the marker
in ciphertext, archive tampering and truncation, authentication before output,
recovery-key export/import and wrong-password rejection, and rejection of a
payload over 32 MiB without publishing an archive.

Verification run on this Windows machine:

- `powershell.exe -NoProfile -ExecutionPolicy Bypass -File tests/windows/test-archive-crypto.ps1` — passed (Windows PowerShell 5.1).
- `pwsh -File tests/windows/test-archive-crypto.ps1` — passed (PowerShell 7).
- `git diff --check` — passed.

The first run exposed and fixed three implementation/test defects: the reserved
PowerShell `$input` name collided with the stream parameter, `MemoryStream`'s
backing buffer included unused capacity in the encrypted payload, and the
recovery importer cleared its returned key before the caller could use it. The
PowerShell 5.1 run also required explicitly loading the `System.Security`
assembly and using the framework-compatible random-byte API.

This is synthetic evidence for the crypto layer only. No production dump,
application secret, remote restore, real archive, or scheduled task was used.
It does not yet establish a production backup cadence, offsite durability,
freshness target, or restore RPO/RTO; Windows availability is irregular and
there is no external storage in the current setup. Production use remains
pending parent review and the separate SSH/restore workflow.
