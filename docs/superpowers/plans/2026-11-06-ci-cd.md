# CI/CD implementation plan

Scope authorized in chat: make tripples25/darim public; tests, image build,
manual production deployment using existing Docker Compose. Server not ready.

1. Check tracked files/history for secrets, publish repository as public.
2. Retain existing integration/browser tests and separate image build after tests.
3. Package immutable image and deployment configuration; manual main-only SSH deploy.
4. Restrict production environment to main; SSH secrets are environment-scoped.
5. Validate workflow on GitHub, follow tests/build to completion; document server setup.

Deployment design: server-local .env, verified SSH host key, fixed Compose project,
backup before updating an existing app, explicit migrations, HTTPS health check.
No automatic rollback across migrations. Serverless validation cannot prove deployment.
